# Beadle Buddy (website demo)

A static website: `index.html` plus an `assets` folder. No server, no build step, no database.
It runs entirely in the visitor's browser. **Nothing is saved or sent anywhere**; refreshing the
page starts over. All names are typed in by the user (none are built in).

## Put it on GitHub Pages (free)

1. Create a GitHub account and a new **public** repository, for example `beadle-buddy`.
2. Click **Add file > Upload files** and drag in **everything in this folder**
   (`index.html`, `assets`, `.nojekyll`, `README.md`). Keep the folder structure. Click **Commit changes**.
3. Open the repository **Settings > Pages**. Under *Build and deployment*, set *Source* to
   **Deploy from a branch**, *Branch* to **main** and the folder to **/ (root)**, then **Save**.
4. Wait a minute or two. The address appears at the top of that page:
   `https://YOUR-USERNAME.github.io/beadle-buddy/`

To test on your own computer first, just double-click `index.html`.

## How to use it

1. Open **Beadle**, pick a section, then **Class list** and type the student names.
2. Open the **Beadle Sheet**: tap Mark all present, fix the exceptions, then Send to Teacher.
3. Open **Teacher** to approve (or send back with a reason), and **APFOR** to check records,
   decide excuse letters and admit late students to class.
